Platform.Ontology is open source. There are two licenses, one for the code and one for the data.

| Part | License | What it covers |
| --- | --- | --- |
| Code | [MIT](https://opensource.org/license/mit) | Build scripts, the simulator, the wiki and this documentation site |
| Data | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | Everything under `data/`, `schema/` and the published JSON bundles |

## Using the data

You may copy, share and build on the data, including for commercial work, as long as you give credit.

A good credit line looks like this:

> Data from Platform.Ontology (https://platformontology.lol), licensed CC BY 4.0.

Link back to the site or to a specific capability page when you can. If you change the data, say so.

## Using the code

The MIT license lets you use, copy, modify and distribute the code with very few limits. Keep the copyright notice and license text with any copy.

## Sources and trademarks

Capability pages link to the official documentation, specifications and research they are based on. Those sources keep their own licenses and copyrights. Names such as Android, iPhone, Chrome, Safari and Firefox belong to their owners and are used here only to describe what their products do.
