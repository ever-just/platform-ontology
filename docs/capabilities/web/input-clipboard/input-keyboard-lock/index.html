Keyboard Lock

Captures keys like Escape and Alt+Tab while in fullscreen.

In one line

Can capture keys like Escape and Alt+Tab while the page is full screen

Captures keys like Escape and Alt+Tab while in fullscreen.

Lets games and remote desktops receive keys the browser normally keeps, so a site can trap Escape or Ctrl+W. Works only in fullscreen; a long-press of Escape always exits.

What it can and can't do

Reach 2 of 4While in full screen

What the user does: You tap a full screen button in a game or remote desktop

It can

  • Take over keys the browser normally keeps, such as Escape or Alt+Tab
  • Pass those keys to a game or remote desktop session
  • Do this only while the page is in full screen

It cannot

  • Trap you for good; holding Escape for about 2 seconds always lets you out
  • Capture keys when the page is not full screen
  • Work in Firefox or Safari
  • Capture the operating system's own protected shortcuts like Ctrl+Alt+Delete

How it differs between platforms: Chrome and Edge support it on desktop. Firefox and Safari do not.

Typical flow

  1. Enter fullscreen
  2. keyboard.lock(keys)
  3. Locked keys sent to the page
  4. Hold Escape 2 seconds to exit

Technical limits

  • Cannot capture Ctrl+Alt+Del or OS shortcuts
  • Chromium only

The story

What it is

Lets a page grab keys like Escape and Alt+Tab when full screen.

For you

You go full screen in a game or remote desktop and keys like Escape go to the game instead of closing it. A message usually says 'Hold Escape to exit full screen'. You feel the page has taken over your keyboard.

For makers

Cloud games and remote work tools need every key to reach the remote computer. Without it, a press of Escape or Alt+Tab would break the stream. Makers also like how it keeps players inside the app.

Where you see it

TypeExampleApps

creativeA web video editing or 3D tool receives all shortcuts while in full screen.None named
securityA bad page could try to trap you in full screen, which is why the browser shows a hold to exit message.None named

Risks

  • Fake lock screens
