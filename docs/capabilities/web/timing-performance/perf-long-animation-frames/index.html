Long Animation Frames (LoAF)

Reports frames that took over 50 ms and which scripts caused them.

Gets silentlySpeed and timingPerformance APIWeb browsersWhile you use it

In one line

Can see slow page frames and which scripts caused them

Reports frames that took over 50 ms and which scripts caused them.

Shows slow frames with script URLs, durations, forced layout and blocking time. Gives site owners (and third party scripts) a view of device speed and which embedded scripts exist on the page.

What it can and can't do

Reach 2 of 4Silent, while the page runs

What the user does: Nothing. It happens as the page runs

It can

  • List frames that took over 50 ms
  • Name which script or link made them slow
  • Learn your device speed
  • See how embedded or outside scripts affect the page

It cannot

  • Work in Firefox or Safari
  • Ask permission first
  • See your files
  • Know who you are by itself

How it differs between platforms: Chrome and Edge support it. Firefox and Safari do not.

The story

What it is

Browsers report screen updates that took over 50 milliseconds and which scripts caused them.

For you

You never see it. It is a tool that points to the exact script that made a page stutter. When teams fix those scripts, your scrolling and taps feel smoother.

For makers

Developers use it to find slow third party scripts, such as ads and chat widgets, and push vendors to fix or remove them. It helps meet Core Web Vitals targets and keeps real time apps smooth.

Risks

  • Exposes third party scripts
  • Chromium only so far

What the platform says

  • Google Chrome: Long Animation Frames API. Chrome says it helps developers find which scripts make pages feel janky or slow to respond.
