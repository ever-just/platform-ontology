CapabilityKindIn one line

Direct Sockets (TCP, UDP)Asks you firstCan open raw network connections only inside signed, installed apps, never on normal sites

HSTS supercookieUsed to track youCan try to tag your browser with a hidden secure site ID, though it is limited

HTTP/2 connection fingerprint (Akamai)Used to track youCan tell which browser or tool you use from how your connection starts up
HTTP/3 and QUIC fingerprintUsed to track youCan tell which browser or tool you use from the first packet of a fast connection
IP geolocationGets silentlyCan guess your country, region and city from your IP address
IP masking (Private Relay, IP Protection, Tor)Gets silentlyCan see only a relay's address when you browse with Private Relay, IP Protection or Tor
IPv6 prefix and interface ID stabilityUsed to track youCan tell your home network apart by its stable IPv6 address, even after clearing cookies
JA3 TLS client fingerprintUsed to track youCan guess which browser or app you use from how your connection starts
JA4+ network fingerprint familyUsed to track youCan recognize your browser or app from several quiet network clues, even when shuffled
Local Network Access (LNA) permissionAsks you firstCan connect to devices on your home network, only if you allow it in Chrome

Loopback network access (loopback-network)Asks you firstCan talk to programs on your own computer, only if you allow it in Chrome
Network client hints (ECT, RTT, Downlink)Gets silentlyCan see your rough connection speed and delay in each request, if it asks first
Network Information (downlink, rtt, effectiveType)Gets silentlyCan see roughly how fast and what type your connection is, in Chrome and Edge
Network Information APIGets silentlyCan see roughly how fast your connection is and whether you turned on data saving
Online and offline stateGets silentlyCan tell if your device thinks it is online, and when that changes
Private Access Tokens and PACTGets silentlyCan check that you are probably a real device without learning who you are
Referer and Origin headersGets silentlyCan tell which site you came from, usually just the site name, not the page

TLS session resumption trackingUsed to track youCan link your visits across sites on one server if your browser reuses a ticket
VPN, proxy and Tor detectionGets silentlyCan guess whether you are hiding behind a VPN, proxy or Tor, but not always correctly
WebRTC ICE host candidates (mDNS)Gets silentlyCan try to find your device's home network address, but browsers now hide it
WebRTC local IP discoveryGets silentlyCan try to learn your device's home network address and public address through a call setup
WebRTC STUN public IP discoveryGets silentlyCan find the public internet address of your real connection, even when some VPNs hide it
